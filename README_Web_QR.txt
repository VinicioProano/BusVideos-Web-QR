BUSVIDEOS – WEB QR

Esta carpeta contiene la página intermedia del QR.

Función:
- Si la app está instalada → abrir BusVideos
- Si no está instalada → descargar BusVideos.apk

QR definitivo apunta a:
https://busvideos.github.io/busvideos/

Notas:
- El QR NO debe apuntar directo al APK
- index.html y BusVideos.apk deben estar juntos
